# Word-membership reconstruction

`reconstruction/dictionary_lookup.c` represents CODE 15 resource offsets
0x0198..0x0276. The section primitive at +0x01c8 compares a NUL-terminated byte
string with four-byte big-endian records. Low byte is the letter, bit 8 is word
acceptance, bit 9 terminates a sibling list, and arithmetic right shift by ten
produces the child index. Matching the final character returns the raw bit-8
value (256), not a normalized Boolean.

Sibling ordering uses signed byte comparison. The source preserves that and
the signed child shift, rather than assuming unsigned ASCII/table arithmetic.
There are no original malformed-table bounds or cycle checks. The isolated
instruction at +0x0232 has no incoming edge from the decoded routine; its call
is explicitly noted rather than assigned invented reachable behavior.

Two wrappers differ: +0x0198 uses the signed 16-bit section count at A5-10936;
+0x023e walks descriptors at A5-11960 until a zero root index. Both normalize
nonzero results to one. They must not be merged into one equivalent wrapper.

## Saved original-runtime tables

The existing 128 MiB RAM snapshot has CurrentA5 0x07cf5500 and an exact full
CODE 15 match at 0x07c9a330. Its first two descriptors contain roots 122166 and
145476. Every byte of their table storage matches the preserved Maven data fork:

| Section | Data-fork offset | Table bytes | Root |
|---|---:|---:|---:|
| 0 | 12 | 488768 | 122166 |
| 1 | 488780 | 582008 | 145476 |

The following descriptor has root zero. The separate counted-wrapper count is
zero in this snapshot, despite those populated descriptors. Evidence, hashes
and sample reconstructed outputs are in `dictionary-snapshot.json`.

The compiled C accepts `aa`, `aardvark`, `cat`, `dog`, and `queen` in both
sections; `quizzify` only in section 1. Empty input, `a`, `zzzzzz` and uppercase
`CAT` return zero in both. These are results from reconstructed C on exact
snapshot data, not captured results from original function calls.

Five host tests exercise raw terminal return, signed sibling comparison, last
sibling stopping, a valid backward child reference and the differing wrapper
termination rules. Fourteen focused host tests pass in total. Natural call and
return comparisons have now been captured as described below.

## Natural Word List calls

`dictionary-live-calls.json` combines ten captured section-0 calls from Maven's
Word List UI. Original and reconstructed return values matched in all cases:

| Original result | Words |
|---|---|
| 256 | act, fiz, fizz, fizzy, fuzz, fuzzy, if |
| 0 | quizzify, fy, qi |

These are membership results in this preserved section, not statements about
present-day word-list validity or rejection by the application's combined lists.
Every call preserved D5-D7/A4 and advanced SP four bytes on returning, matching
the original C calling convention. The complete live CODE 15 resource and all
488,768 bytes of the selected table were verified before comparison. The C was
compiled during capture and run on those byte-identical table contents. No
function calls, inputs, registers or memory were injected; the words arose
from normal CAT and QUIZZIFY Word List requests.

`scripts/capture_dictionary_calls.py` resolves an already-loaded CODE 15 or
waits at its counted/terminated wrapper stubs and follows original LoadSeg.
It obtains application A5 from CurrentA5, rather than relying on whichever
Toolbox routine is paused. Dictionary reads are chunked to 8 KiB because a
single full-table GDB memory request was rejected. Each capture leaves the
guest paused and removes its breakpoints. The disposable VM has been stopped.

## What the counted wrapper means here

The live return frame identifies CODE 12+0x04c8 as the wrapper's caller, with
the full CODE 12 resource verified through current loaded jump entries. See
`dictionary-wrapper-caller.json`. At +0x04c4 it calls A5+0x0322 on the candidate
word at A5-9760. Nonzero membership skips the insertion call at +0x04d2.

The outer loop at CODE 12+0x02d8 iterates section index D6 and writes it into
A5-10936 at +0x02ea/+0x0300. Therefore this count is the number of earlier
sections to consult during generation, not the total populated-section count.
Its captured value was one when testing QUIZZIFY. The code suppresses words
already present in earlier sections, allowing later sections to add unique
words. This explains both the zero count in the earlier idle snapshot and
the natural negative lookups observed while generating valid combined-list words.

Remaining limits: live calls for section 1, wrapper return comparisons and
broader exceptional/table-edge behavior are still unverified. The synthetic
signed-byte/backward-child tests cover reconstructed semantics only.

## Overall scope

`reconstruction-inventory.json`, generated by `scripts/reconstruction_inventory.py`,
lists all corrected CODE resources and source-associated routine ranges. The
range sizes are not completion percentages: some operations use external ABI
adapters, resources include data, and several paths lack runtime validation.
There is no complete application rebuild or full-game verification yet. The
next work should expand into the now-identified CODE 12 enumeration caller and
move-generation routines, while broadening validation where it can reveal new
behavior. Startup verification alone does not establish application completeness.
